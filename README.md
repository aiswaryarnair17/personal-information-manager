# Personal Information Manager

## Project Description
This is a beginner-friendly Python console application that collects and displays personal information with input validation and formatted output.

## Features
- Input validation
- Age calculation in months
- Clean formatted display
- Error handling using try-except
- Modular functions

## Technologies Used
- Python 3

## How to Run
1. Clone the repository
2. Navigate to project folder
3. Run:
   python personal_info.py
